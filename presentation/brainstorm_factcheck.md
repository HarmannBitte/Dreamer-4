# Fact-check of the Gemini brainstorm against the Dreamer 4 paper (arXiv 2509.24527)

Checked 2026-09-22 against the local PDF (`dreamer4_resources/papers/`). Verdict: the numbers are almost all correct — the brainstorm is unusually reliable. The items below are the ones to fix or soften before they go on a slide.

## Needs correcting

| Brainstorm claim | What the paper says | Fix |
|---|---|---|
| Ablation cascade referred to as "Table 3" (Deep-Tech slide 13 header) | The design cascade is **Table 2**. Table 3 is the comparison of agent setups (Dreamer 3 / VPT / Dreamer 4). | Rename. |
| "GQA … erhöht die Ausführungsgeschwindigkeit von 9,1 auf 23,2 FPS" | 9.1 → 18.9 FPS comes from *time attention only every 4th layer*; GQA alone takes 18.9 → 23.2 (FVD 70 → 71). The **final** model runs at **21.4 FPS** because the last step (N_z = 256 spatial tokens) costs speed again. | Attribute the jump to factorisation + GQA together; quote 21 FPS as the final number. |
| Genie 3 mermaid: "Diffusion Transformers", "Diverse reale Web-Videos und Spiele", "Benötigt viele GPUs für Echtzeit" | The paper says this about the *class* of controllable video models ("based on scalable architectures, such as diffusion transformers", "often require many GPUs to simulate a single scene in real time"). Genie 3's architecture, data and hardware are undisclosed (no paper); Project Genie serves one accelerator per user session. What the paper states specifically about Genie 3: camera actions + one generic "interact" button only. | Label the Genie 3 boxes as "controllable video models in general" or use the hedged wording of `diagrams/genie3_stack_diagram.png`. |
| Nether result: "steuert … sofort mit einer 80%igen Präzision" | The model trained with Overworld-only actions reaches **76 % of the PSNR and 80 % of the SSIM** of a model trained with all actions (Figure 7). It is a relative video-quality ratio, not a control-precision score. | Say "80 % of the SSIM of the fully-labelled model". |
| "10 h Aktionen: 53 % PSNR / 75 % SSIM; 100 h: 85 % PSNR / 100 % SSIM" | Correct — but again relative to the all-actions model (and SSIM saturates early). | Keep, add "relative to the model trained with all actions". |
| λ-return written once with v_t and once with v_{t+1} | Equation 10 of the paper literally reads R_t^λ = r_t + γ c_t ((1−λ) v_t + λ R_{t+1}^λ), R_T^λ = v_T (c_t = non-terminal indicator). The textbook Dreamer form uses v_{t+1}; the paper's v_t is most likely a typo. | Use one form consistently; if you quote the paper, quote it as printed. |
| "Bootstrap-Loss … unendlich lange Videos" / "Infinite rollouts" | The paper claims stable long autoregressive rollouts; the ablation generates 384-frame (~20 s) videos without context; the context window is 9.6 s. | "Long, stable rollouts", not infinite. |
| "MAE … verleiht Objektpermanenz", "Register-Tokens fangen Aufmerksamkeits-Spitzen ab", "GQA halbiert den Durchsatz-Flaschenhals" | Interpretations, not statements of the paper. The paper: MAE "improves representations"; registers cited (ref 25) without explanation; GQA "reduces the KV cache size further". | Fine as speaker intuition; do not attribute to the paper. |
| "Dreamer 4 verdreifacht" (iron pickaxe) | 29.0 % vs 11.2 % = 2.6×; the paper's wording is "nearly tripling". | Say "nearly triples". |
| "Transformer bleibt komplett eingefroren" in imagination training | Correct for the main results — but footnote † adds that fine-tuning the full transformer "provides small additional benefits at higher computational cost" (requires keeping dynamics, prior and reward losses on). | Worth a half-sentence. |
| "Dreamer 4 … 100-mal weniger Daten" | Confirmed by the Table 3 caption ("100× less data than previous keyboard and mouse agents"). Note VPT used the *same* 2.5K contractor hours; the difference is 270K web hours + 194K online hours. | Keep, phrase precisely. |
| "Jeweils nach 48 h Training auf 384-Frame-Generierungen" (FVD protocol) | Correct: each ablation model trains 48 h, then 1,024 videos × 384 frames without context, actions from a fixed BC policy, FVD on 16-frame chunks vs the hold-out set. | Keep. |

## Verified as stated (no action needed)

- Data: VPT contractor subsets 6–10 = 2,541 h; 360×640 at 20 FPS; 90/10 split by 5-min recording; 23 binary keys; mouse μ-law, 11 bins per axis → 121 classes (foveated discretisation); 20 tasks with sparse binary rewards from VPT inventory events; 50/50 mixture of uniform and task-relevant sequences (BC loss only on the relevant half, dynamics loss only on the uniform half).
- Tokenizer: zero-pad to 384×640, 16×16 patches → 960 tokens; bottleneck (N_b = 512) × (D_b = 16) reshaped to N_z = 256 × 32; tanh; L = L_MSE + 0.2 L_LPIPS; MAE dropout p ~ U(0, 0.9) with a learned mask embedding.
- Dynamics: shortcut forcing, K = 4; x-prediction with (1−τ)² x-space bootstrap loss and ½·sg(b′+b″) target; ramp weight w(τ) = 0.9τ + 0.1; time attention every 4th layer; GQA on all attention layers; register tokens; learned "no action" embedding for unlabeled video; context 192 frames = 9.6 s.
- Agent: agent tokens attend to everything, nothing attends back (causal-confusion argument); MTP with L = 8 for policy and reward; symexp-twohot reward and value heads; TD λ-returns with γ = 0.997; PMPO (Abdolmaleki et al., "Preference optimization as probabilistic inference") on the sign of A_t = R_t^λ − v_t, α = 0.5, β = 0.3, *reverse* KL to the frozen BC prior; rollouts start from dataset contexts, one rollout per context.
- Compute: 2 B parameters (400 M tokenizer + 1.6 B dynamics), 256–1,024 TPU-v5p, batch size 1 per device, FSDP.
- Table 2 cascade: 306 → 875 (K = 4) → 329 → 326 → 151 → 102 → 80 → 70 → 71 → 91 → 91 → 66 → 57; 0.8 FPS baseline, 21.4 FPS final.
- Table 7: VPT (finetuned) stick 52.6 %, wooden pickaxe 0.0 %; VLA (Gemma 3) log 98.5, crafting table 97.2, stone pickaxe 76.7, iron pickaxe 11.2, diamond 0.0; Dreamer 4 log 99.1, crafting table 98.5, stone pickaxe 90.1, iron pickaxe 29.0, diamond 0.7 (1,000 episodes, 60 min each). VLA = Gemma 3 fine-tuned with MTP on the relevant sequences.
- Table 3: Dreamer 3 64×64 + inventory, abstract crafting actions, 1.4K h online; VPT (RL) 128×128, 2.5K + 270K + 194K h; VPT (BC) 2.5K + 270K; Dreamer 4 360×640, 2.5K, offline.
- Table 1: MineWorld 1.2B / 384×224 / 0.8 s / 2 FPS / not evaluable (parallel decoding needs actions in advance); Lucid-v1 1.1B / 640×360 / 1.0 s / 44 FPS / 0/16; Oasis small 500M / 640×360 / 1.6 s / 20 FPS / 0/16; Oasis large ? / 360×360 / 1.6 s / ~5 FPS / 5/16, "autocompletion" failure mode; Dreamer 4 2B / 640×360 / 9.6 s / 21 FPS / 14/16.
- Humans: ~20 min to a diamond on average = ~24,000 actions ("over 20,000" also appears). Nether/End: 76 % PSNR, 80 % SSIM. SOAR: 180 h, 7-D relative end-effector actions, 256×256 at 5 FPS. Epic Kitchens 100: 100 h egocentric video, no actions.
