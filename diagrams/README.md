# Companion stack diagrams

Three standalone graphics drawn in the same style as the Dreamer 4 system diagram (`presentation/stack_diagram.png`, slides 13–14 of the deck): numbered boxes, explicit data-flow arrows, one page each, 2666 px wide PNG plus an SVG. The comparison matrix (split in two) and the Genie 3 diagram (its two rows) also appear on slides 28–29 and 41–42 of the deck; the VPT diagram is standalone. The scripts that regenerate them live in `presentation/` (matplotlib + Carlito; they write to `/home/user/…`, adjust the output paths at the bottom of each script).

| File | Script | What it shows | Sources |
|---|---|---|---|
| `vpt_stack_diagram.png` / `.svg` | `presentation/make_vpt_stack_diagram.py` | OpenAI's Video PreTraining (Baker et al. 2022) as a system: ~270k h of web video → CLIP/SVM filtering → 70k h `web_clean`; 1,962 h of contractor data; the 0.5 B non-causal inverse dynamics model that pseudo-labels the video; the 0.5 B causal foundation policy; BC fine-tuning and the PPG + KL-to-prior RL loop; plus a "Where Dreamer 4 differs" panel. | arXiv 2206.11795 (local copy in `papers/`) |
| `minecraft_world_models_stack.png` / `.svg` | `presentation/make_wm_stack_comparison.py` | Stack-by-stack comparison matrix of the five Minecraft world models of Dreamer 4's Table 1 — MineWorld, Lucid-v1, Oasis small, Oasis large, Dreamer 4 — across data, tokenizer, backbone, objective, actions, context (bars), resolution, speed on one H100 (bars), openness and the 16-task human play test (dot strip). | Dreamer 4 Table 1; MineWorld arXiv 2504.08388; Lucid-v1 write-up and repo; Oasis technical post and `open-oasis` repo |
| `genie3_stack_diagram.png` / `.svg` | `presentation/make_genie3_stack_diagram.py` | Google DeepMind's Genie 3 (Aug 2025) as far as it is public: inputs (text prompt, navigation actions, promptable world events), the auto-regressive world model as DeepMind describes it, output/serving, the Genie 1 → 2 → 3 → Project Genie lineage, the human play loop, the SIMA 2 agent self-improvement loop, stated limitations and the differences to Dreamer 4. No Genie 3 paper exists, so every element is marked as **stated by DeepMind**, **inferred** (amber, dashed — the recipe DeepMind published for Genie 2) or **undisclosed** (grey). The widely repeated "11 B parameters / 200k h of gaming video" numbers are Genie 1's and are flagged as such. | Genie 3 blog post and model page (deepmind.google), Genie 2 blog (Dec 2024), Genie 1 paper (arXiv 2402.15391), SIMA 2 announcement (Nov 2025), Project Genie launch coverage (Jan 2026) |

Shared conventions: 0–100 coordinate system, font scale 1.1, palette NAVY `#14213D` / BLUE `#2A56D6` / INK `#1F2937` / GREY `#6B7280` with AMBER `#B7791F` reserved for "inferred / not stated" content and GREEN `#1B7F5C` for the VPT-specific elements.
